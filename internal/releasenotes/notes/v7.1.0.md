BombVault 7.1.0 builds on 7.0.0 with one major addition: **multiple off-site destinations per domain**.

## Added

- **Multiple off-site destinations per domain.** Each domain now supports newline-separated off-site URLs (restic and/or rclone), allowing replication to multiple backup targets in a single run. Credential-safe multi-target iteration — a failure on one target never blocks the others. The Settings and Config pages show an add/remove list of off-site URLs instead of a single input.
